# Bundled BPE corpus

`alice_in_wonderland.txt` is the unmodified `carroll-alice.txt` file from the NLTK project's Project Gutenberg selections archive.

- Work: *Alice's Adventures in Wonderland* (1865), Lewis Carroll.
- Original collection: Project Gutenberg, <https://www.gutenberg.org/ebooks/11>.
- Download source: <https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/corpora/gutenberg.zip>.
- Archive member: `gutenberg/carroll-alice.txt`.
- SHA-256: `5ce9042c0d8536b072b61d4c7c4e6d70c72d9dbb5f3d816261326d9280749266`.

The work is in the public domain. `gutenberg-README.txt` is the unmodified collection README supplied in the same archive. It contains the collection's original source and legal notices. The pipeline reads the local text only; it never downloads data.
